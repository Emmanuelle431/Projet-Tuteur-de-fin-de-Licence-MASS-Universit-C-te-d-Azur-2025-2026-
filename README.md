# Projet-Tuteur-de-fin-de-Licence-MASS-Universit-C-te-d-Azur-2025-2026-
Analyse statistique de l'impact du travail salarié sur la réussite académique des étudiants, à partir d'un questionnaire administré auprès de 61 étudiants de Licence et Master. Méthodes utilisées : tests du khi-deux, régression logistique (Python &amp; Excel).
